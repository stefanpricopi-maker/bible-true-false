# Decision addendum — Pre-literate color UI

**Date:** 2026-08-20  
**Status:** locked (user)

## Facts

User requirement: children who cannot read must be able to play using **only colored buttons**.

## Mapping

| Meaning | Color |
|---------|-------|
| Adevărat (True) | Green (Verde) |
| Fals (False) | Red (Roșu) |
| Jucător 1 | Blue (Albastru) |
| Jucător 2 | Yellow (Galben) |

## Implications

- Play controls must not require reading text labels.
- Welcome / handoff audio should teach and use color names („verde”, „roșu”, „albastru”, „galben”).
- Optional parent-only text is allowed if hidden from the kids play path.
- Shape/position may reinforce color for color-vision deficiency; still no letters on answer buttons.
