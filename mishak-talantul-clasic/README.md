# Antrenament Clasic — Mishak

Antrenament **coop** părinte–copil pentru tipurile de întrebări din secțiunea **Clasic** a concursului Talantul în Negoț.

**Neoficial.** Nu conține întrebările oficiale. Site concurs: https://talantulinnegot.com/

## Dev

```bash
npm install
npm test
npm run dev
```

App pe http://localhost:5173/ (doar `npm run dev`, fără comentarii pe aceeași linie).
